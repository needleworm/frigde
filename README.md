# 📊 스마트 엑셀 규격별 자동 병합기 (Excel Schema Merger)

> **순수 HTML, CSS, JavaScript로 구현된 무설치 웹 애플리케이션**  
> 여러 개의 엑셀 파일(`.xlsx`, `.xls`, `.csv`)을 업로드하면 헤더(열 구성)를 자동으로 판독하여 **동일 규격끼리 그룹화하고 하나의 파일로 병합**해줍니다.

---

## 🌟 주요 특징 및 기능

1. **무설치 / 100% 로컬 보안 처리**
   - 별도의 빌드 도구나 백엔드 서버 없이 브라우저 단독으로 동작합니다.
   - 모든 엑셀 데이터는 사용자의 PC(브라우저 메모리)에서만 처리되며 외부 서버로 전송되지 않아 매우 안전합니다.

2. **스마트 규격 자동 분류 (Smart Schema Clustering)**
   - **열 순서 무관 유연 일치 (Flexible Match)**: 컬럼 순서가 서로 다른 파일이라도 열 이름이 같으면 동일 규격으로 인식하여 정확히 매핑 병합합니다.
   - **엄격 일치 (Strict Match)**: 열 순서까지 완전히 동일한 파일만 묶는 모드도 지원합니다.
   - 공백 자동 제거 및 대소문자 매칭 지원.

3. **풍부한 병합 및 가공 옵션**
   - **`_원본파일명` 및 `_시트명` 열 자동 추가**: 병합된 각 데이터 행이 어떤 파일(또는 시트)에서 온 것인지 맨 앞 열에 기록하여 출처 추적 가능.
   - **중복 행 자동 제거**: 동일한 중복 데이터를 1건만 남기고 스마트 필터링.
   - **빈 행 건너뛰기**: 내용이 없는 빈 행 자동 제거.
   - **헤더 위치 행 지정**: 1행, 2행 또는 첫 번째 유효 데이터 행 자동 감지.
   - **다중 시트 지원**: 첫 번째 시트만 사용하거나 모든 시트를 각각 독립 규격으로 분석.

4. **다양한 다운로드 및 내보내기 방식**
   - **규격별 개별 다운로드**: 각 그룹별 `.xlsx` 또는 UTF-8 BOM 지원 `.csv` 다운로드.
   - **통합 엑셀 다운로드 (Multi-Sheet Workbook)**: 분류된 모든 규격 그룹을 1개의 엑셀 파일 내 각각의 시트(`규격_1`, `규격_2` 등)로 분리하여 한 번에 저장.
   - **일괄 ZIP 압축 다운로드**: 모든 규격별 엑셀 파일들을 `.zip` 압축 파일로 묶어서 다운로드.
   - **클립보드 복사**: 데이터를 복사하여 엑셀이나 구글 스프레드시트에 바로 붙여넣기(Ctrl+V).

5. **현대적인 프리미엄 디자인**
   - Glassmorphism & 다크/라이트 테마 토글.
   - 드래그 앤 드롭, 실시간 테이블 검색/필터링, 프로그레스 바.
   - **샘플 데이터 1초 체험 버튼**: 예제 엑셀 파일들을 즉시 생성하여 테스트해 볼 수 있습니다.

## 🚀 실행 방법

### 방법 1. 파일 더블 클릭으로 바로 열기
1. 탐색기에서 `index.html` 파일을 더블 클릭하여 크롬, 엣지, 웨일 등 최신 웹 브라우저에서 엽니다.

### 방법 2. 간단한 로컬 웹 서버로 열기 (권장)
```bash
# Python 내장 서버 실행
python -m http.server 8080

# 또는 npx serve 실행
npx serve .
```
브라우저에서 `http://localhost:8080`으로 접속합니다.

## 📁 파일 구조

```
새 폴더/
├── index.html        # 메인 웹 페이지 구조 (시맨틱 마크업, 모달, 드롭존)
├── style.css         # 모던 글래스모피즘 스타일시트 (다크/라이트 테마, 반응형 UI)
├── parser.js         # SheetJS 기반 엑셀/CSV 파서 및 스키마 시그니처 분석 엔진
├── merger.js         # 데이터 병합, 중복 제거, 엑셀/CSV/ZIP 생성 및 내보내기 엔진
├── app.js            # 이벤트 바인딩, 상태 관리, 실시간 테이블 렌더링 컨트롤러
└── README.md         # 사용 설명서
```
